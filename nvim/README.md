# 💤 LazyVim

## HelloWorld

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

---

## 🛠️ Plugin Status & Keymaps

Use this table to verify how your new `markview.nvim` split-panel keybindings look when rendered.

| Feature / Action | Keybinding | Command | Description |
| :--- | :---: | :--- | :--- |
| **Inline Toggle** | `<leader>mv` | `:Markview toggle` | Flips preview on/off in current buffer |
| **Split Toggle** | `<leader>ms` | `:Markview splitToggle` | Opens/closes a side-by-side split panel |
| **Force Open** | `<leader>mo` | `:Markview splitOpen` | Explicitly opens the split view |
| **Force Close** | `<leader>mc` | `:Markview splitClose` | Explicitly closes the split view |

---

## 🚀 Quick Start Features

* **Lazy Loading:** 68 plugins configured to load only when needed.
* **Treesitter Integration:** High-performance syntax highlighting for code blocks.
* **Live Previews:** Real-time updates as you type in your split panel.
