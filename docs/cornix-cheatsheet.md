# Cornix cheat sheet

Hold a thumb key to switch layer. Let go to type again.

| Hold | Layer | For |
|---|---|---|
| left middle thumb | **NUM** | Numbers, symbols, arrows |
| right outer thumb | **NAV** | Workspaces and window focus |
| left outer thumb | **WIN** | Move and resize windows |
| right middle thumb | **APP** | Apps and menus |

## Knobs

- Left: volume · Right: scroll
- In **NAV**, left knob: Prev WS / Next WS
- In **APP**, left knob: Prev / Next

## Combos

J + K → Esc · A + B / S + B → previous / next tmux window

`1×` = applies to the next key only · BT = Bluetooth device
